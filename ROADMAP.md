# Roadmap

## Near-Term

- improve documentation navigation and onboarding
- expand FAQ and maintainer guidance
- strengthen analysis utilities for public outputs
- add clearer configuration examples and validation notes

## Medium-Term

- improve reproducibility reporting around model runs
- add more public-facing examples of expected outputs
- reduce friction around optional external tooling
- clarify migration guidance when public interfaces evolve

## Long-Term

- evaluate a cleaner separation between public wrappers and vendored legacy core
- improve packaging and installation ergonomics
- expand generic analysis and reporting capabilities for new-basin workflows

## Non-Goals

- publishing private basin archives
- shipping large raw forcing bundles
- turning the repository into a case-specific thesis companion archive
