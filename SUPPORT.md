# Support

## Where To Start

For most users, the best entrypoints are:

- [README.md](README.md)
- [docs/README.md](docs/README.md)
- [docs/workflow_overview.md](docs/workflow_overview.md)

## How To Ask For Help

When reporting a problem, include:

- the entrypoint script you ran
- the relevant config keys
- the expected behavior
- the actual behavior or error
- whether the issue reproduces on the synthetic example

## What Not To Post

Do not post:

- private basin names
- local absolute paths unless sanitized
- private discharge files
- private run snapshots

## Issue Routing

- reproducible bug: open a bug report
- reusable workflow improvement: open a feature request
- security-sensitive problem: follow [SECURITY.md](SECURITY.md)
