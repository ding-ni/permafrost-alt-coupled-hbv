# Code of Conduct

This repository is maintained as a respectful public research-software project.

## Expected Behavior

- Be respectful and technically concrete.
- Critique ideas, implementations, and documentation, not people.
- Keep discussions relevant to the repository and its public scope.
- Avoid posting private basin data, private run outputs, or sensitive identifiers.

## Unacceptable Behavior

- personal attacks or harassment
- discriminatory or abusive language
- intentionally posting private or restricted data
- derailing technical discussions with hostile behavior

## Maintainer Guidance

Maintainers may remove content or restrict participation when behavior harms collaboration, violates repository scope, or exposes private material.
