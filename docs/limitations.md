# Limitations

## Scientific Limitations

- Performance depends strongly on forcing quality and observation quality.
- ALT coupling remains a model-based hypothesis test, not a direct physical measurement of subsurface processes.
- Glacier, snow, and runoff-source interpretation should be treated as model-derived diagnostics unless independently validated.

## Workflow Limitations

- Some preprocessing steps rely on optional external GIS or download tooling.
- The public release does not include raw data bundles.
- The synthetic example is only a smoke test.

## Repository Limitations

- This repository is method-focused, not case-study-complete.
- Paper-only figures and narrative interpretation are intentionally excluded.
- Public documentation avoids study-area-specific heuristics even if those existed in earlier internal versions.
